# Very Cool Game

## Описание

Небольшой игровой прототип на Pygame: игрок управляет квадратным персонажем, уклоняется от преследующего врага и пытается продержаться как можно дольше.

Это очень компактный проект в духе первого учебного action-прототипа. В нём уже есть базовый игровой цикл, движение, столкновения, полоска здоровья и экран проигрыша.

## Что реализовано

- управление персонажем с клавиатуры;
- преследующий враг;
- столкновения и уменьшение здоровья;
- простой HUD с полоской HP;
- экран `Game Over`.

## Стек

- Python
- Pygame

## Управление

- `WASD` или стрелки: движение;
- `Q`: выход из игры;
- закрытие окна: завершение приложения.
